# Volt Cat - Secret Immortality System

## Overview
A hidden God Mode has been implemented into the game engine. It is not mentioned anywhere in the game's UI or control guide.

---

## Secret Key
- **Key**: `S` (keyboard `KeyS`, case-insensitive)

---

## How It Works
1. Press `S` at any time while playing (or on the title screen).
2. **Effects when activated**:
   - **Immortality (God Mode)**: The cat becomes completely invulnerable to all obstacles.
   - **No Game Over**: The game will never crash or trigger the Game Over screen.
   - **Continuous Run**: Any obstacle the cat collides with shatters instantly into particles and awards bonus score (+250 pts), allowing the sprint to continue infinitely.
   - **Subtle Feedback**: When `S` is pressed to activate, a brief cyan energy burst and audio chime confirm activation without alerting onlookers.
3. Press `S` again at any time to toggle Immortality back off if you wish to return to standard mortal gameplay.
